# Sources for the frontier-wire digest — the raw material of every edition.
#
# One URL per line. Blank lines and lines starting with # are ignored; an inline
# "# note" after a URL is fine (only the first token is used). Dead or moved feeds
# are skipped automatically on fetch, so optimistic entries are safe.
#
# ORDER MATTERS. digest.py keeps the newest few items per feed and caps the total,
# walking this file top-down. The cloud routine's sandbox blocks egress to almost
# everything EXCEPT raw.githubusercontent.com, so the reliably-reachable MIRRORS are
# listed FIRST — they keep the digest alive from inside the sandbox. Everything else
# enriches the digest on an open network and is skipped silently when blocked.
#
# The feed-gardener skill (.claude/skills/feed-gardener/) tends this file: it prunes
# dead feeds, adds new sources, and hunts for general-news mirrors hosted on
# raw.githubusercontent.com — the standing quest, since today's mirrors are tech-only.
