На GitHub набирает популярность каталог из 200+ инструментов, которые не просят регистрациюA GitHub directory of 200+ tools that never ask you to sign up is picking up steam

Проект NoSignups (бывший FckSignups) собирает открытые веб-инструменты без аккаунтов, куки и аналитики — и вырос до 2,9 тысячи звёзд на честном раздражении регистрационными стенами.The NoSignups project (formerly FckSignups) catalogs open-source web tools with no accounts, cookies, or analytics — and has grown to 2.9k stars on plain frustration with sign-up walls.

Репозиторий BraveOPotato/FckSignups, новая запись в трендах GitHub под №12 (50 новых звёзд за день, TypeScript), сегодня официально называется NoSignups и живёт на отдельном сайте nosignups.net. Это не инструмент, а каталог: подборка открытых веб-сервисов, которыми можно пользоваться прямо в браузере без создания аккаунта.

Правило отбора простое и сформулировано как манифест: инструмент должен работать сразу, без регистрационной стены; данные пользователя принадлежат пользователю, а не тому, кто их собирает; открытый код предпочтительнее закрытого; простота важнее лишней сложности. На сегодня в каталоге больше 200 инструментов, распределённых по девяти категориям — продуктивность, дизайн и графика, разработка, работа с текстом и документами, приватность, утилиты, данные и аналитика, медиа, образование. У каждой записи — описание, ссылка на GitHub, лицензия и теги для поиска. Заявки на добавление новых инструментов принимаются через issues на GitHub, с ограничением на длину описания в 140 символов и тремя-пятью тегами; при этом «рекомендованные» инструменты редакция отбирает вручную — за уникальность, а не за сходство с уже добавленными.

Сам проект держит открытую лицензию GPL-3.0, собрал 2,9 тысячи звёзд и 200 форков, а вокруг него уже сложилось небольшое сообщество на Reddit (r/fucksignups). На сайте, по заявлению авторов, нет ни куки, ни аналитики.

Почему это важно

На фоне бесконечных ИИ-агентов и фреймворков с сомнительными счётчиками звёзд каталог NoSignups — вещь предельно приземлённая: не решает никакой инфраструктурной задачи, а просто собирает то, что уже работает без лишних препятствий. Раздражение регистрационными стенами и сбором данных — не новая тема, но именно то, что проект вырос органически вокруг простого списка ссылок, а не вокруг обещаний искусственного интеллекта, само по себе показательно для 2026 года.

The BraveOPotato/FckSignups repository, a new entry on GitHub's trending page at #12 (50 new stars in a day, TypeScript), now officially goes by NoSignups and lives on its own site, nosignups.net. It isn't a tool itself but a directory: a curated list of open-source web services usable directly in a browser, no account required.

The selection rule is simple and stated as a manifesto: a tool must work immediately with no registration wall; user data belongs to the user, not whoever collects it; open source is preferred over proprietary; simplicity beats unnecessary complexity. The directory currently lists more than 200 tools across nine categories — productivity, design and graphics, development, writing and docs, privacy, utilities, data and analytics, media, and education. Each entry carries a description, a GitHub link, license information, and searchable tags. New submissions go through GitHub issues, capped at 140 characters per description with three to five tags, while "featured" tools are picked manually for being distinctive rather than similar to what's already listed.

The project itself is GPL-3.0 licensed, has 2.9k stars and 200 forks, and has built a small community on Reddit (r/fucksignups). The site, per its own description, runs with no cookies and no analytics.

Why it matters

Against an endless stream of AI agents and frameworks with dubious star counts, the NoSignups directory is refreshingly unglamorous: it solves no infrastructure problem, it just collects things that already work without extra friction. Frustration with sign-up walls and data harvesting isn't new, but the fact that this project grew organically around a plain list of links, rather than around AI promises, says something about 2026 on its own.
