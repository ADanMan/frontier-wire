## Русская версия

Microsoft [начала развёртывание нового Windows Search](https://blogs.windows.com/windows-insider/2026/10/07/from-searching-to-doing-building-a-faster-more-streamlined-windows-search/) 7 октября. Пока это предварительная версия для участников Windows Insider в Experimental, с английским языком на первом этапе. Изменение затрагивает поиск на панели задач. Поэтому сообщение стоит читать как начало испытания привычного интерфейса, а не как обновление, уже одинаково доступное всем владельцам Windows и на любом языке.

Новая версия построена на WinUI 3. Компания сообщает, что ранние испытания показали улучшения скорости и расхода памяти, но в публикации не приводит сопоставимых численных результатов. Здесь важно сохранить масштаб утверждения: есть заявленное направление оптимизации, а не опубликованная таблица независимых измерений. Для повседневного поиска заметность улучшения будет определяться реальным компьютером, его содержимым и тем, какие запросы человек обычно вводит.

Интерфейс собирает результаты в один список вместо прежнего сочетания списка слева и крупной области просмотра справа. Microsoft объясняет решение наблюдением, что почти все клики приходились на левую часть. Также заявлены улучшения сопоставления опечаток и синонимов. Смысл такой перестройки достаточно приземлённый: когда ищешь конкретный файл, лишняя панель может занимать место, не помогая выбрать правильную строку. Но удобство нового списка ещё предстоит оценить участникам испытания.

Отдельное новшество — действия прямо из поиска. В примерах Microsoft можно переключить тёмную тему или Bluetooth, уменьшить яркость, отключить звук и управлять окнами. Поиск становится коротким маршрутом к знакомым настройкам. Это не равнозначно универсальному агенту, который выполнит любое сформулированное поручение: в объявлении описан ограниченный набор повседневных операций, постепенно расширяемый по результатам обратной связи.

Сроки дополнительных возможностей различаются. Встроенные предпросмотры файлов, более подробные сведения и богатые веб-ответы компания относит к более позднему этапу этого года. Действия с подключённым через Phone Link телефоном названы будущими. Перенос нового поиска в меню «Пуск» намечен на следующий год; в начальном preview поиск из «Пуска» остаётся прежним. Один рекламный экран с демонстрацией функций поэтому не доказывает их одновременную доступность в текущей сборке.

### Почему это важно

Поиск — место, где небольшая экономия шагов повторяется много раз за день. Microsoft пытается совместить более спокойную выдачу с возможностью сразу изменить настройку. Для читателя главный вывод пока в границах запуска: английский Experimental и панель задач, а дальше — несколько отдельных этапов. Обратная связь должна показать, действительно ли новый список помогает находить нужное и насколько точно интерфейс понимает запрос. Успех такого изменения будет виден в обычных коротких действиях, а не только в эффектной демонстрации возможностей будущей версии.

## English version

Microsoft [began rolling out a new Windows Search experience](https://blogs.windows.com/windows-insider/2026/10/07/from-searching-to-doing-building-a-faster-more-streamlined-windows-search/) on October 7. It is initially an English-language preview for Windows Insiders in the Experimental channel, covering search from the taskbar. The announcement should therefore be read as the start of a test, rather than a change already available to every Windows user in every language.

The new experience uses WinUI 3. Microsoft says early testing found improvements in speed and memory use, but the post does not publish numerical results that readers could compare. The claim is a direction of improvement, not an independently measured performance table. How noticeable it feels in daily use will depend on a person's computer, its contents and the queries they actually enter.

Results now appear in one list rather than a list on the left alongside a large preview area on the right. Microsoft attributes that decision to data showing that nearly all clicks in the current interface came from the left-hand results. It also describes better matching for typos and synonyms. The practical idea is straightforward: when someone wants a particular file, a large panel may consume space without making the correct result easier to choose. Preview users will help establish whether the redesigned list solves that problem.

Inline actions are a separate addition. Microsoft's examples include changing the theme or Bluetooth setting, dimming the display, muting audio and arranging windows. Search becomes a shorter route to familiar controls. That is a bounded collection of everyday operations, rather than evidence of an all-purpose agent capable of carrying out any request. The company says it will expand the foundation over time, using feedback about how search understands intent.

The roadmap contains several different stages. Inline file previews, richer file details and web answers are planned for later this year. Actions involving a Phone Link-connected handset are described as coming soon. Bringing the new experience into the Start menu is work for next year; Start-menu searches retain the existing interface in the initial preview. A demonstration showing several capabilities should not be mistaken for proof that they all ship together in the current build.

### Why it matters

Search is a place where saving a few steps can matter repeatedly throughout a day. Microsoft is combining a quieter results view with direct access to simple actions. The immediate scope is still narrow: English, Experimental and the taskbar, followed by separate future stages. User feedback needs to establish whether results are easier to recognize and whether commands are understood reliably. The success of a change like this will be apparent in small, ordinary interactions, not just in a polished demonstration of what a later version might do.
